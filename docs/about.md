# About oscal

A LinkML schema of the Open Security Controls Assessment Language (OSCAL) 1.2.3, NIST's language for control catalogs, profiles, component definitions, system security plans, assessment plans and results, plans of action and milestones, and control mappings. Each of the eight models is a module of the schema, and every element renders a definition of OSCAL's metaschema at the v1.2.3 release.
